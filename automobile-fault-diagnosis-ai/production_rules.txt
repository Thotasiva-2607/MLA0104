AUTOMOBILE FAULT DIAGNOSIS
PRODUCTION RULE MODEL

Production rules represent automobile diagnostic knowledge
using IF-THEN statements.

--------------------------------------------------
BASIC PRODUCTION RULES
--------------------------------------------------

R1:
IF engine is overheating
THEN cooling-system fault is suspected.

R2:
IF vehicle has starting failure
THEN battery fault is suspected.

R3:
IF abnormal engine noise is observed
THEN engine/mechanical fault is suspected.

R4:
IF vehicle has low mileage
THEN fuel-system fault is suspected.

R5:
IF warning indicator is ON
THEN sensor/monitored-system fault is suspected.

--------------------------------------------------
COMBINED PRODUCTION RULES
--------------------------------------------------

R6:
IF engine is overheating AND coolant level is low
THEN coolant-related fault is suspected.

R7:
IF engine is overheating AND radiator fan is not working
THEN radiator/fan fault is suspected.

R8:
IF vehicle has starting failure AND battery is weak
THEN battery fault is suspected.

R9:
IF vehicle has starting failure AND starter motor does not operate
THEN starter-motor fault is suspected.

R10:
IF abnormal engine noise AND engine oil level is low
THEN lubrication-related fault is suspected.

R11:
IF abnormal engine noise AND knocking sound is observed
THEN engine-knocking fault is suspected.

R12:
IF low mileage AND fuel consumption is high
THEN fuel-efficiency fault is suspected.

R13:
IF low mileage AND air filter is clogged
THEN air-intake problem is suspected.

R14:
IF warning indicator is ON AND engine warning is displayed
THEN engine-related fault is suspected.

R15:
IF warning indicator is ON AND battery warning is displayed
THEN charging-system fault is suspected.

R16:
IF overheating AND warning indicator is ON
THEN cooling-system fault is highly suspected.

R17:
IF starting failure AND warning indicator is ON
THEN electrical-system fault is suspected.

R18:
IF abnormal noise AND low mileage
THEN engine-performance fault is suspected.

--------------------------------------------------
EXAMPLE OF RULE APPLICATION
--------------------------------------------------

Fact:
Engine is overheating.

Rule:
IF engine is overheating
THEN cooling-system fault is suspected.

Conclusion:
Cooling-system fault is suspected.

Another example:

Facts:
Engine is overheating.
Warning indicator is ON.

Rule:
IF overheating AND warning indicator is ON
THEN cooling-system fault is highly suspected.

Conclusion:
Cooling-system fault is highly suspected.
