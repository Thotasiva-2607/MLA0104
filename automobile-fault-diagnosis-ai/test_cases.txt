AUTOMOBILE FAULT DIAGNOSIS
PROLOG TEST CASES

The following test cases are designed for the
automobile_diagnosis.pl Prolog program.

--------------------------------------------------
TEST CASE 1: CHECK OVERHEATING
--------------------------------------------------

Query:

?- overheating(car1).

Expected Output:

true.

Explanation:

The fact overheating(car1) is present in the
knowledge base.

--------------------------------------------------
TEST CASE 2: CHECK STARTING FAILURE
--------------------------------------------------

Query:

?- starting_failure(car1).

Expected Output:

true.

Explanation:

The fact starting_failure(car1) is present.

--------------------------------------------------
TEST CASE 3: CHECK COOLING-SYSTEM FAULT
--------------------------------------------------

Query:

?- cooling_fault(car1).

Expected Output:

true.

Reason:

overheating(car1) is true.

Rule:

cooling_fault(X) :-
    overheating(X).

--------------------------------------------------
TEST CASE 4: CHECK BATTERY FAULT
--------------------------------------------------

Query:

?- battery_fault(car1).

Expected Output:

true.

Reason:

starting_failure(car1) is true.

--------------------------------------------------
TEST CASE 5: CHECK ENGINE FAULT
--------------------------------------------------

Query:

?- engine_fault(car1).

Expected Output:

true.

Reason:

abnormal_noise(car1) is true.

--------------------------------------------------
TEST CASE 6: CHECK FUEL-SYSTEM FAULT
--------------------------------------------------

Query:

?- fuel_fault(car1).

Expected Output:

true.

Reason:

low_mileage(car1) is true.

--------------------------------------------------
TEST CASE 7: CHECK SENSOR FAULT
--------------------------------------------------

Query:

?- sensor_fault(car1).

Expected Output:

true.

Reason:

warning_on(car1) is true.

--------------------------------------------------
TEST CASE 8: CHECK HIGHLY SUSPECTED
COOLING FAULT
--------------------------------------------------

Query:

?- cooling_fault_high(car1).

Expected Output:

true.

Reason:

Both conditions are true:

overheating(car1)
warning_on(car1)

--------------------------------------------------
TEST CASE 9: CHECK ELECTRICAL FAULT
--------------------------------------------------

Query:

?- electrical_fault(car1).

Expected Output:

true.

Reason:

Both conditions are true:

starting_failure(car1)
warning_on(car1)

--------------------------------------------------
TEST CASE 10: CHECK POSSIBLE FAULT
--------------------------------------------------

Query:

?- possible_fault(car1, cooling_system_fault).

Expected Output:

true.

--------------------------------------------------
TEST CASE 11: NEGATIVE TEST
--------------------------------------------------

Query:

?- overheating(car2).

Expected Output:

false.

Explanation:

There is no fact stating that car2 is overheating.

--------------------------------------------------
SUMMARY
--------------------------------------------------

The Prolog program successfully derives diagnostic
conclusions from the available automobile symptoms.

The test cases verify facts, basic diagnostic rules,
combined diagnostic rules, and a negative query.
